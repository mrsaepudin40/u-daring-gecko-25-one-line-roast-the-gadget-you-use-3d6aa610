A program that writes one original line roasting a gadget used every day
to `/output/entry.txt`, for the
[make.fun competition](https://make.fun/c/u-daring-gecko-25-one-line-roast-the-gadget-you-use-3d6aa610).

## The line

> My air fryer needs twenty minutes to preheat for food that cooks in ten — it spends more time getting ready than the meal does.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

`main.py` is a plain static writer: no network, no secrets, no dynamic
code, no reads outside the repository.
